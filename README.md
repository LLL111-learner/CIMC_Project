# 2026西门子杯工业嵌入式系统开发初赛 - 工业数据采集终端

本项目为 2026 年 CIMC“西门子杯”中国智能制造挑战赛 **工业嵌入式系统开发方向（初赛）** 参赛作品，基于兆易创新 GD32F470VET6 主控芯片裸机开发，完整实现了工业级模拟量采集终端的全部功能，包含数据采集、自定义串口协议交互、参数持久化、自动上报、告警管理、低功耗运行与 Bootloader OTA 固件升级。

---

## 一、硬件平台
### 核心主控
- 主控芯片：GD32F470VET6（Cortex-M4 内核，主频 168MHz）
- 通信接口：USART1（RS485），默认波特率 19200

### 板载外设
| 模块 | 芯片型号 | 接口 | 功能说明 |
|------|----------|------|----------|
| 高精度ADC | GD30AD3344 | SPI | 16位多通道模拟量采集，支持PT100温度测量 |
| 数据存储 | GD25Q40E | SPI | 4Mbit NOR Flash，用于参数与告警记录持久化 |
| 人机交互 | 0.91寸 OLED | I2C | 双行显示队伍编号与系统运行状态 |
| 数模转换 | 内置DAC | - | 输出可调模拟电压，支持回读验证 |
| 实时时钟 | 内置RTC | - | 提供UTC时间戳，支持掉电走时 |

### 独立电源板
- 主控芯片：GD30DC1354 同步降压DC-DC
- 输入范围：9V ~ 36V DC，额定工业24V供电
- 输出规格：5V / 2A
- 保护机制：输入防反接、过流保护、短路保护、欠压锁定
- 性能指标：满载转换效率 ≥ 85%，输出纹波峰峰值 ≤ 50mV

## 二、软件架构
项目严格遵循赛题分层规范，分为 **Bootloader** 与 **APP** 两个独立工程，均采用三层架构设计，满足赛题目录评分要求。

### 分层设计规范
| 层级 | 目录 | 职责说明 |
|------|------|----------|
| 硬件驱动层 | `Driver/` | 存放UART、SPI、I2C、OLED、Flash、RTC、ADC、DAC等全部底层驱动代码 |
| 通讯协议层 | `Protocol/` | 实现协议帧解析、应答组帧、CRC16-Modbus校验、字符串编解码 |
| 业务逻辑层 | `Function/` | 数据采样、变比计算、阈值告警、参数管理、自动上报、升级流程等业务逻辑 |

### Flash 空间划分
严格按照赛题要求分配内部Flash地址：
| 分区 | 起始地址 | 结束地址 | 大小 | 用途 |
|------|----------|----------|------|------|
| Bootloader 区 | 0x08000000 | 0x0800FFFF | 64KB | 启动引导与固件升级 |
| 参数区 | 0x08010000 | 0x08010FFF | 4KB | 存储系统参数，升级不擦除 |
| App 运行区 | 0x08011000 | 0x08030FFF | 128KB | 用户程序运行区域 |
| App 备份区 | 0x08031000 | 0x08050FFF | 128KB | 固件备份与回滚 |
| 固件暂存区 | 0x08051000 | 0x08070FFF | 128KB | OTA升级固件临时存放 |

## 三、核心功能实现
### 1. 多通道数据采集
- CH0：板载电位器模拟量采集，支持软件滤波与变比换算
- CH1：DAC输出回读采集，验证DAC输出精度
- CH2：外部ADC连接PT100测温板，转换为实际温度值
- 全部通道数据采用 IEEE 754 单精度浮点数格式上报，大端序传输

### 2. 自定义串口通信协议
- 帧格式：起始标志 + 设备ID + 帧类型 + 命令字 + 长度 + 协议版本 + 内容 + CRC16 + 结束标志
- 传输方式：全部协议帧以十六进制对应的ASCII字符串传输，非二进制Hex
- 支持帧类型：命令下发帧、应答帧、心跳帧、错误告警帧
- 异常处理：CRC错误、长度错误、非法命令字均返回标准错误应答帧

### 3. 参数持久化
以下参数写入Flash，设备重启后自动恢复：
- CH0 / CH1 通道变比
- CH0 / CH1 告警阈值
- 设备ID、串口波特率配置
- 历史告警记录（最多保存10条，支持查询与清除）

### 4. 自动采集上报
- 支持 1s / 3s / 5s 三档上报间隔配置
- 上报内容：UTC时间戳 + CH0数据 + CH1数据
- 上报期间仅响应停止命令，屏蔽其他指令，符合赛题评测要求
- OLED 状态自动切换为 `AutoSample`，采集指示灯常亮

### 5. 告警管理
- 支持主动上报告警与仅记录两种模式
- 超阈值时自动记录告警信息：时间 | 通道 | 阈值 | 实际值
- 支持查询最近10条告警记录、清除全部告警记录
- 无告警记录时查询返回 `empty`

### 6. 低功耗睡眠唤醒
- 支持MCU深度睡眠模式，RTC闹钟定时唤醒
- 睡眠时长固定10秒，唤醒后输出字符串 `instrument wakeup`
- 睡眠期间仅电源板供电，可通过电流表观测功耗变化

### 7. Bootloader OTA 升级
- 上电默认5秒静默等待，无升级指令自动跳转APP
- 收到升级指令后重启进入Bootloader，10秒倒计时等待固件
- 支持固件切片接收（每片256字节）、魔术字校验（`5AA5C33C`）
- 校验通过后执行固件搬运，升级完成自动跳转新APP

### 8. 状态指示
- OLED双行固定显示：第一行队伍编号，第二行系统状态（`Bootloader` / `AutoSample` / `IDLE`）
- 系统状态灯：进入APP后以1秒周期闪烁
- 采集工作灯：自动上报模式时常亮，其余状态熄灭

## 五、开发与使用说明
### 开发环境
- IDE：Keil MDK 5.38 及以上
- 固件库：GD32F4xx 标准外设库
- 编译优化：-O0 / -O1 优化等级
- 下载工具：J-Link / ST-Link / 串口ISP

### 烧录步骤
1.  打开 Bootloader 工程，编译后烧录到 0x08000000 起始地址
2.  打开 APP 工程，编译后烧录到 0x08011000 起始地址
3.  移除仿真器，独立电源板供电上电，系统自动进入APP运行

### 默认参数
| 参数 | 默认值 |
|------|--------|
| 设备ID | 可自行配置，范围 0x0001 ~ 0xFFFE |
| 串口波特率 | 19200（8数据位、1停止位、无校验） |
| 固件版本 | 2.0.1.0 |
| 通道变比 | 1.0 |
| 上报间隔 | 1秒 |

### 评测流程
1.  上位机通过 RS485 连接设备，串口默认 19200 波特率
2.  输入评测密码，启动自动评测
3.  系统自动完成 A~N 共14个模块、38项测试
4.  评测结束自动生成分数报告文件

## 七、注意事项
1.  **通信格式**：协议帧必须以ASCII十六进制字符串形式传输，禁止直接发送二进制字节，否则评测无法识别。
2.  **脱机运行**：正式评测与演示必须移除SWD仿真器，采用电源板独立供电，否则按违规处理。
3.  **默认波特率**：系统出厂默认波特率必须为19200，自动评测启动时会强制切换，不对则全程通信失败。
4.  **目录规范**：严格遵循 Driver / Protocol / Function 三层目录结构，不符合要求会扣除20分。
5.  **字符串输出**：告警查询、Boot提示、睡眠唤醒回复为纯ASCII字符串，不进行协议帧封装。
6.  **ID过滤**：非广播地址且设备ID不匹配的帧必须直接丢弃，不得返回任何应答。
